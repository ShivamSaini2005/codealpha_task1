# Social Media Platform

A modern and responsive social media web application where users can create profiles, share posts, like and comment on posts, and follow other users. This project is developed using React, TypeScript, Express.js, and MongoDB.

---

## Features

### User Authentication
- User Registration
- Secure Login
- JWT Authentication
- Password Encryption

### User Profile
- View Profile
- Edit Profile
- Update Profile Picture
- View Followers & Following

### Posts
- Create New Post
- Edit Post
- Delete Post
- Upload Images

### Social Features
- Like & Unlike Posts
- Add Comments
- Follow & Unfollow Users
- Personalized News Feed

### Additional Features
- Search Users
- Notifications
- Responsive Design
- Fast Performance

## Installation

### Prerequisites

- Node.js (v18 or above)
- MongoDB

### Clone Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root.

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

### Run Project

```bash
npm run dev
```
